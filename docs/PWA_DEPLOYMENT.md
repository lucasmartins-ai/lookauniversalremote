# LookARemote — Production PWA Deployment Guide

This guide details the deployment, hosting, service worker configuration, and device installation procedures for the LookARemote PWA Web Client.

---

## 1. Overview

LookARemote's web client is designed as a standalone, installable Progressive Web Application (PWA). It provides an ultra-low latency mobile controller interface for desktops and Smart TVs.

- **Primary Production Host**: [Vercel](https://vercel.com) (or any static HTTPS host)
- **Production URL**: `https://remote.lookaberry.com`
- **Secondary Distribution**: Standalone packaged release ZIP from GitHub Actions release artifacts (`lookaremote-pwa-web-client.zip`).

---

## 2. Build Pipeline & Commands

### Prerequisites
- Node.js 20+
- npm 10+

### Monorepo Build Commands
```bash
# Clean install monorepo dependencies
npm ci

# Build protocol-types dependency first
npm run build --workspace=@lookaremote/protocol-types

# Build production PWA bundle
npm run build --workspace=@lookaremote/web-client
```

### Production Output Directory
Output is generated at: `apps/web-client/dist/`

The built bundle contains:
- `index.html` — Single page application shell with preconnected Google Fonts and PWA meta tags
- `manifest.webmanifest` — W3C Web App Manifest
- `sw.js` — Service Worker script generated by Workbox via `vite-plugin-pwa`
- `workbox-*.js` — Workbox runtime library
- `icon-192.png` & `icon-512.png` — Standard and maskable app icons
- `assets/` — Version-hashed JavaScript chunks and CSS stylesheets

## 3. Vercel Deployment

Deploying via Vercel ensures global edge distribution, automated HTTPS certificate management, and zero-downtime rollouts.

### Deployment Configuration (`vercel.json`)
The project includes a root `vercel.json` configuring:
1. **Build Command**: `npm run build --workspace=@lookaremote/protocol-types && npm run build --workspace=@lookaremote/web-client`
2. **Output Directory**: `apps/web-client/dist`
3. **Cache Headers**:
   - `/sw.js` & `/manifest.webmanifest`: `public, max-age=0, must-revalidate` (ensures immediate PWA updates)
   - `/assets/*`: `public, max-age=31536000, immutable` (long-term caching for immutable hashed assets)
4. **Security & Permissions Policy**:
   - `accelerometer=(self)`, `gyroscope=(self)`, `magnetometer=(self)` for IMU AirMouse
   - `screen-wake-lock=(self)` for screen wake lock during gaming
   - `camera=(self)` for QR code scanner pairing
5. **SPA Rewrites**: Seamless routing fallback to `/index.html`.

### Deploying via Vercel CLI
```bash
npx vercel --prod
```

### Custom Domain Configuration
1. In Vercel Project Settings → Domains: add `remote.lookaberry.com`.
2. Configure DNS CNAME record: `remote.lookaberry.com` → `cname.vercel-dns.com`.
3. Vercel automatically issues and renews Let's Encrypt / DigiCert SSL certificates.

---

## 4. Service Worker & Cache Strategy

- **Strategy**: Cache-First for static pre-cached assets (`.js`, `.css`, `.html`, `.svg`, `.png`, `.woff2`) with automated background updates (`registerType: 'autoUpdate'`).
- **Google Fonts Cache**: Runtime caching using `CacheFirst` with a 1-year expiration policy.
- **Cache Invalidation**: On every new deployment, Vite generates new chunk content hashes. When the browser detects an updated `sw.js`, Workbox claims clients (`clientsClaim: true`, `skipWaiting: true`) and purges outdated caches (`cleanupOutdatedCaches: true`).

## 5. Mobile Device Installation

### iOS Safari (iPhone / iPad)
1. Open Safari and navigate to `https://remote.lookaberry.com`.
2. Tap the **Share** button (box with an upward arrow) in the toolbar.
3. Scroll down and tap **Add to Home Screen**.
4. Confirm by tapping **Add**.
5. Launch LookARemote from your home screen for full-screen, standalone mode with zero browser address bar chrome.

### Android Chrome
1. Open Chrome and navigate to `https://remote.lookaberry.com`.
2. Look for the automated **Add LookARemote to Home Screen** banner, or tap the three-dot menu and select **Install App** / **Add to Home screen**.
3. Tap **Install**.
4. The PWA will be added to your app drawer and home screen as a standalone WebAPK.
